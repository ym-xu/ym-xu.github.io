Method

Every morning (06:00 UTC) a GitHub Action asks the arXiv API for the last {{ $d.weeks }} weeks of papers in cs.CV, cs.CL, cs.IR and neighbouring categories whose title or abstract mentions documents, OCR, layout, tables, charts, forms and the like. Papers that don’t look visual — text-only “documents” — are dropped.

Each of the {{ len $d.subfields }} subfields is a keyword rule. A rule found in the title counts three times, in the abstract once; a subfield is tagged at a score of two or more, so a single passing mention (“we run an OCR engine”) is not enough. The highest-scoring subfield is the paper’s primary one. “Rising terms” compares how often a title word or phrase appears in the last four weeks with the weeks before. The rules live in scripts/fetch_survey.py; this is a rough instrument, so expect some misfiled papers.1
