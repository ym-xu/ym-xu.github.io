Method

Every morning (06:00 UTC) a GitHub Action queries the arXiv API for recent papers in cs.CV, cs.CL, cs.IR and neighbouring categories whose title or abstract mentions documents, OCR, layout, tables, charts, forms and the like. Papers that don’t look visual — text-only “documents” — are dropped. The rest are filed into the {{ len $d.subfields }} subfields above by keyword rules; a paper can sit in several, so shares add up to more than 100%. The rules live in scripts/fetch_survey.py, and the whole thing is a rough instrument: expect some misfiled papers.1
