写给做临床研究、但还没写过代码的医生。这门课的终点是一篇**预测模型的论文**: 用病人治疗前就知道的信息(阴道壁厚度、施源器、治疗方式……),预测换一种计划方案后剂量会怎么变,并且说清楚这个预测对新病人有多准、能不能拿来做决定。学完以后,你应该能看懂这样一篇论文的每一步,能参与写方法和结果,也能回答审稿人的问题。

常见的统计课讲的是**解释**: 哪个因素和结局有关,OR 是多少。这门课讲的是**预测**: 对还没见过的病人预测得准不准。两者用的模型可以一样,检验的办法完全不同,这是这门课的主线。

建议按顺序学: **第 1–4 课**学 Python 本身(变量、表格、汇总、画图),**第 5–7 课**补上够用的统计基础,**第 8–9 课**是从解释到预测的转折(交叉验证、数据泄漏),**第 10–12 课**讲模型,**第 13–16 课**讲怎么判断模型够不够好,**第 17–18 课**讲样本量和怎么写成论文。

每一课都有这几样:

- **能运行的代码**: 每个代码块右上角有 **▶ Run**,点一下就在浏览器里运行,结果和图显示在代码下面。代码可以直接改了再运行,不用先在电脑上装任何东西。第一次点 Run 要下载 Python,大约十几秒;用到 scikit-learn 等大包的课,第一次还要再等一会儿,之后就快了。在自己电脑上安装放在第 18 课。
- **同一个模拟队列**: 从第 2 课起,所有例子都用同一批模拟病人(每人在同一个 CT 上有 5 mm、体积优化、图形优化三套计划)。这些数字都是编的,不是任何研究的结果;它们怎么产生的,可以看[源码](/python-ml/cohort.py)。
- **先讲它在算什么**: 每个方法写成几步具体的操作,配一个临床上熟悉的例子,再用代码演示,不用一个术语去解释另一个术语。
- **写进论文**: 每课最后一栏,写这一步在论文的方法部分用英文怎么写,审稿人可能问什么,怎么回答。
