## 这次要审计什么

你所在的放疗科想回顾一下: 过去几年做的宫颈癌近距离放疗,剂量给得怎么样?

局部晚期宫颈癌的标准治疗是同步放化疗: 先做盆腔外照射(常用 45 Gy,分 25 次),再做**近距离放疗**(brachytherapy)。近距离放疗时,把施源器放进宫腔和阴道穹隆,让放射源在里面停留几分钟,给宫颈的肿瘤补上很高的剂量。现在的做法是每次治疗前做 MRI 或 CT,按当时的肿瘤来做计划,叫图像引导的近距离放疗。数据里的每位病人做了 4 次。

- **HR-CTV**(高危临床靶区): 近距离时残留的肿瘤加上整个宫颈。它的 **D90**(90% 的体积至少受到的剂量)代表靶区照得够不够。
- **直肠和膀胱的 D2cc**: 受照最多的 2 cm³ 至少受到的剂量,代表最热的那一小块。
- 两种施源器: **IC**(intracavitary)单纯腔内;**IC/IS**(加 interstitial)腔内加插植针。肿瘤大、形状不规则时加针,把剂量送到腔内施源器够不到的地方。
- 每次的剂量换算成 **EQD2**,再把外照射和 4 次近距离加起来。靶区用 α/β = 10,直肠和膀胱用 α/β = 3。

科里的审计标准有三条:

| | 标准(总 EQD2) |
|---|---|
| HR-CTV D90 | 不低于 85 Gy |
| 直肠 D2cc | 低于 65 Gy |
| 膀胱 D2cc | 低于 80 Gy |

这三个数取自 EMBRACE II 研究的剂量要求,为了练习做了简化: 85 Gy 是那里对靶区处方剂量的硬性下限,65 Gy 和 80 Gy 是直肠和膀胱的计划目标(硬性上限是 75 Gy 和 90 Gy)。出处: Pötter R, Tanderup K, Kirisits C, 等. [The EMBRACE II study](https://pmc.ncbi.nlm.nih.gov/articles/PMC5862686/). *Clin Transl Radiat Oncol* 2018;9:48–60。真实工作里的标准,以你所在单位的规范为准。

审计要回答三个问题:

1. 我们的病人里,有多大比例达到了这三条标准?
2. 加了插植针的病人,靶区剂量是不是更好?肿瘤大的时候呢?
3. 直肠剂量高的病人,晚期直肠副作用是不是更多?

> 🔬 数据是模拟的: 200 位病人,数字都是编的,只是样子像一个科室的审计数据。它不是任何真实病人的记录,也不是任何研究的结果;怎么产生的,可以看[源码](/python/cervix.py)。

## 数据里有什么

| 列 | 含义 |
|---|---|
| `id` | 病人编号 |
| `age`、`stage`、`histology` | 年龄、FIGO 分期、病理(`SCC` 鳞癌,`AC` 腺癌) |
| `hrctv_vol` | 近距离时 HR-CTV 的体积(cm³) |
| `technique` | 施源器: `IC` 或 `IC/IS` |
| `ebrt_gy`、`ebrt_fx` | 外照射的总剂量(Gy)和次数 |
| `d90_1` … `d90_4` | 第 1–4 次近距离的 HR-CTV D90(Gy) |
| `rectum_1` … `rectum_4` | 第 1–4 次近距离的直肠 D2cc(Gy) |
| `bladder_1` … `bladder_4` | 第 1–4 次近距离的膀胱 D2cc(Gy) |

随访另有一张表: 随访时间和有没有出现 2 级及以上的晚期直肠副作用。
